Download .sh installer file from https://github.com/darbit-ru/bitrix_docker_installer and run it.

Настройки push-сервера
После запуска проекта необходимо закончить настройку push-сервера.

На сервер установлена схема Bitrix Push server 2.0 с отдельными контейнерами redis, pub и sub.

Путь для публикации команд внутри docker-сети: http://pub:9010/bitrix/pub/
Публичный путь для подписки клиентов: https://<ваш-домен>/bitrix/sub/
Публичный путь для WebSocket: wss://<ваш-домен>/bitrix/subws/
Код-подпись для взаимодействия с сервером: значение PUSH_SERVER_KEY из .env

Настройки подключения к БД берутся из .env:
сервер БД: DB_HOST
имя БД: MYSQL_DATABASE
пользователь: MYSQL_USER
пароль: MYSQL_PASSWORD
